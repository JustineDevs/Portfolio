# Release v0.1.1

Release notes for `v0.1.1` (since `v0.1.0` / `67f41c1`).

## Highlights

- **CMS / admin**: Console layout uses semantic landmarks; shared admin form styles; live Markdown preview for long-form fields; pending state on primary save actions; dashboard section cards show live counts from Turso.
- **Auth & data**: Google admin sign-in hardening (provider subject, lookups); Drizzle/Turso env loading (`.env` then `.env.local`); documented DB repair and migration helpers under `scripts/db/` and `docs/DATABASE.md`.
- **Legal & discovery**: Configurable Privacy Policy and Terms links (env + `site_settings`) in the footer; Google Search Console site verification on the root layout.
- **Site & content**: About, projects, experience, and resume areas refreshed; GitHub activity / hearts / engagement-related API and UI updates; static legacy JSON removed from `public` in favor of database-backed content.

## Changed

- Project showcase, navbar, footer, social controls, pixel cursor, and related UX polish.
- `pnpm-lock.yaml` / dependency updates; TypeScript and Next config tweaks as needed for the above.

## Removed

- Large static JSON fixtures previously under `public` (e.g. projects / activity history dumps) where replaced by CMS/Turso-backed data.
- Deprecated or unused experience / gallery / timeline pieces per recent refactors (see git history for exact paths).

## Upgrade / ops

- After pulling: run `pnpm install` if the lockfile changed.
- Turso: see `docs/DATABASE.md` for `pnpm db:status`, schema apply, and email-hash repair if you rotate secrets.
- To verify Search Console after deploy: confirm the `google-site-verification` meta is present on the live homepage HTML.
