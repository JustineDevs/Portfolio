# Release v0.1.6

Release notes for `v0.1.6` (since `v0.1.5`).

## Highlights

- Added canonical SEO metadata, Open Graph and Twitter cards, structured data, sitemap coverage, robots rules, and an answer-engine index.
- Expanded project dossiers with corrected banners, awards, certificates, author links, technology details, and archived-record cleanup.
- Added a combined anonymized AI-usage view with provider-aware activity, secure source registries, CSV validation, and public-export documentation.
- Disabled unfinished onboarding and work-site surfaces in production while preserving their development paths and navigation treatment.

## Changed

- Made the HyperKit README banner the single canonical HyperAgent thumbnail and removed the legacy thumbnail path.
- Improved CMS connection handling, experience progress editing, provider logos, homepage technology coverage, and remote asset fallbacks.
- Added automatic changelog indexing through canonical metadata, JSON-LD release records, stable version anchors, and sitemap freshness.
- Documented the SEO keyword strategy, public AI-usage export contract, and provider-usage security model.
