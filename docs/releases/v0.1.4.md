# Release v0.1.4

Release notes for `v0.1.4` (since `v0.1.3`).

## Highlights

- Established the V2 application as the source for both the main portfolio and the separate work portfolio surface.
- Refined the work portfolio with the current projects, experience, education, awards, technology stack, pricing, contact flow, and supplied Universal Music branding.
- Added a continuous payment-method carousel using the supplied CDN brand marks and replaced the legacy cursor with the Magic UI-style pointer.

## Changed

- Added host-aware routing so the main site remains available on port 3000 while the work site is available on port 3001 from the same V2 project.
- Reworked pricing to match the client rate card and added payment methods for GCash, Maya, Wise, PayPal, CIMB, GoTyme, Bitget, and Bybit.
- Updated work portfolio content and layout, including the current project sequence, Discord Moderator experience, education wording, tech stack logos, social links, and contact interactions.
- Added the supplied Universal Music Store logo to the featured project.
- Removed obsolete UI paths and legacy presentation pieces that no longer belong to the V2 portfolio.
