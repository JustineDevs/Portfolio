# Release v0.1.2

Release notes for `v0.1.2` (since `v0.1.1`).

## Highlights

- Added a first-class `/collection` route to the portfolio navbar.
- Turned `JustineDevs/Public-Github-Repo` into a live marketplace-style catalog by parsing category README tables into curated resource entries.
- Kept category-scoped live file inspection for markdown, images, JSON, text, PDFs, and fallback file links.
- Added a collection-specific markdown rendering mode so collection panels and content stay square-edged with bordered boxes.

## Changed

- `Collection` now appears in the main navigation and follows the existing personal-mode routing rules.
- `/collection` fetches live GitHub data at request time and exposes it through a dedicated collection page client.
- The collection data layer now filters hidden repo internals, parses curated resource tables, and surfaces category metadata plus support files.
- Collection detail views now separate curated resource links from category file inspection.
- Markdown rendered inside the collection now resolves relative GitHub links and images correctly.

## Verification

- `npm run build` passed and emitted the `/collection` route in the production build output.
- Architect review passed after follow-up fixes for category descriptions and category filtering.
- `npm test` remains blocked by an existing workspace `esbuild` host/binary mismatch.
