# Release v0.1.3

Release notes for `v0.1.3` (since `v0.1.2`).

## Highlights

- Hardened the Cloudflare migration path with Wrangler/OpenNext configuration, environment-variable guidance, and Cloudflare deployment scripts.
- Removed Vercel-specific tracking/configuration and cleaned up the app for native Cloudflare runtime deployment.
- Tuned the WebGL avatar for visibility, composition, and hover performance, then restored the original projects route behavior when the system pass made it feel too heavy.
- Tightened shared page layout behavior and then reverted the `/projects` shell and footer back to the original compact route experience.

## Changed

- Added Cloudflare deployment files and documentation for Wrangler-based local preview and production deploys.
- Updated image resolution and public-content behavior so remote failures fail softer instead of crashing core pages.
- Reworked the avatar WebGL scene multiple times to resolve freeze behavior, improve framing, and make the portrait readable again.
- Adjusted shared navigation and page shell behavior, then reverted the projects route back to its original presentation when the footer/panel feel became too large.
- Added regression coverage for DB configuration and public-content fallback behavior.

## Verification

- `npm run lint` passed with existing warnings only.
