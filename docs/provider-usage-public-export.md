# Public AI-usage export

The public activity dataset is generated by `pnpm usage:export:public`.

## Source topology

```text
Codex thread history SQLite ─┐
                             ├─> redacted public CSV ─> /api/usage ─> AI Usage panel
Orca usage index JSON ───────┘
Claude archive ─────────────────────────────────────────> Claude Code panel
Cursor export ──────────────────────────────────────────> Cursor panel
```

The exporter reads Codex history in read-only mode and uses the Orca aggregate index. It never reads prompt, response, command, file-path, account, or tool-payload text into the public rows. Codex activity is represented as event counts because the local history does not provide a verified token total. Orca uses its indexed token totals when available.

Each public row contains only the approved metadata contract: timestamp, platform, model/provider, sanitized category, duration, event count, token usage when available, an HMAC-derived session identifier, and source registry key. Session identifiers require `AI_USAGE_EXPORT_SALT`; use a deployment secret and do not commit it. The generated CSV is intentionally public-facing, while raw archives remain local and outside `public/`.

The exporter groups Codex history by thread and UTC day, and deduplicates the direct session-file inventory by device/inode before reporting it. This prevents hard-linked files from being counted twice. It does not publish the inventory paths.
