# SEO and answer-engine keyword strategy

This portfolio should win qualified searches for Justine Lupasi and demonstrate expertise through project-specific, technically precise pages. Search volume and difficulty are intentionally not fabricated; validate these clusters in Google Search Console and Keyword Planner after indexing.

## Priority clusters

| Intent | Keyword cluster | Primary page |
| --- | --- | --- |
| Brand | `Justine Lupasi software developer`, `JustineDevs`, `JSTN portfolio` | `/`, `/about` |
| Hiring / expertise | `AI agent developer portfolio`, `blockchain developer Philippines`, `smart contract developer portfolio` | `/`, `/experience` |
| Technical research | `auditable AI agent workflow`, `AI smart contract development`, `x402 payment infrastructure` | `/projects`, project pages, writing |
| Project discovery | `HyperKit HyperAgent`, `Mandate402 x402 payments`, `MetaWalletGen CLI Ethereum wallet generator`, `Premortem repository audit`, `AmbiOS AI WebMCP` | individual project pages |
| Answer engine | `how to govern AI agent payments`, `how to build auditable smart contract workflows`, `how to validate AI coding agents` | `/blog` and native articles |

## Publishing rules

1. Give every page one clear search intent, title, H1, and canonical URL.
2. Put the plain-language answer near the top, then provide evidence, implementation details, and links.
3. Use real project names and technologies only where the page demonstrates them; avoid repeating broad keywords.
4. Add author, publication date, source links, and update context to technical writing.
5. Review Search Console queries monthly and expand pages that already receive impressions before creating near-duplicates.

## Measurement

Track indexed pages, impressions, clicks, click-through rate, average position, branded vs non-branded queries, and conversions to GitHub/contact links. Submit `/sitemap.xml` in Search Console after the production domain is live.
